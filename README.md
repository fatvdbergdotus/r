# R Programming, Data Science & Machine Learning

A collection of R programming exercises, tutorials, assignments, and projects covering data manipulation, visualization, statistical analysis, and machine learning.

This repository documents practical experience with R and its application to data science, predictive modelling, and data visualization.

## Repository Overview

The repository covers four main areas:

- **R Programming:** Programming fundamentals, advanced programming, and data structures.
- **Data Analysis:** Data frames, data manipulation, and statistical modelling.
- **Data Visualization:** Exploratory data analysis and interactive visualizations.
- **Machine Learning:** Supervised and unsupervised learning algorithms, including practical projects.
